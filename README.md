# CS301 Skills Demo

This repository contains my skills demonstration assignments for CS301.

## Module 1

The `Mod1` folder contains the following Java programs:

- **DistanceSquared.java** – Calculates the squared distance from a point `(x, y)` to the origin `(0, 0)`.
- **TwentyFivePerLine.java** – Prints the numbers from 1000 to 2000 with 25 numbers on each line.
- **Ordered.java** – Checks whether three integers are in ascending or descending order.

## Module 2

The `Mod 2` folder contains the following Java programs:

- **Circles.java** – Draws filled circles of random size at random positions.
- **Stats.java** – Takes an integer command-line argument n, reads floating-point numbers and prints mean and sample standard deviation.
- **Banner.java** – Takes a string s from the command line and display it in banner style moving left to right wrapping back to the beginning.

## Module 3

The `Mod 3` folder contains the following Java programs:

- **AreTriangular.java** –  Takes three double arguments and returns true if they could be the sides of a triangle.
- **Partition.java** – Takes a positive integer N as a command-line argument and prints out all partitions of N.
- **SAT.java** – Estimate the lowest score that will still be admitted..
- **ReverseString.java** - Takes a string and reverses it using recursion.
- **RecursiveBinarySearch.java** - Uses recursive binary search to determine whether a target value occurs in a sorted integer array.

## Module 4

The `Mod 4` folder contains the following Java programs:

- **Once.java** – Reads in a string and prints the first character that appears exactly once in the string.
- **ROT13.java** – Simple encryption scheme used on some Internet newsgroups to conceal potentially offensive postings. It works by cyclically shifting each lowercase or uppercase letter 13 positions.
- **CustomDate.java** – Represents a date. You should be able to create a new Date by specifying the month, day, and year. It should supports methods to compute the number of days between two dates, return the day of the week that a day falls on, etc.
- **SodaMachine.java** - Has methods insertCoin(), getChange(), buy(), etc.

## Module 5

The `Mod 5` folder contains the following Java programs:

- **BinarySearch.java** – An algorithm (hint: binary search!) to find an index i such that a[i] = i if such an index exists in an array a[] of N distinct integers (positive or negative) in ascending order.
- **Parentheses.java** – Reads a string of parentheses, square brackets, and curly braces from standard input and uses a stack to determine whether they are properly balanced..
- **FindKthLargest.java** – An algorithm to find the kth largest one. It should run in O(N) time on random inputs in an array of N elements, not necessarily in ascending order.
- **HashST.java** - Contains the following methods:
    - contains(): Returns true if this symbol table contains the specified key.
    - size(): Returns the number of key-value pairs in this symbol table.
    - keys(): Returns all keys in the symbol table.

## How to Compile

Open a terminal in the `Mod1` folder and compile a program using:

```bash
javac DistanceSquared.java
```

## How to Run

Run the compiled program using:

```bash
java DistanceSquared 3 4
```

The other programs can be compiled and run the same way.
