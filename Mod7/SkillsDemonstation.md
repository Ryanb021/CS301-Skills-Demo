
### NP (Nondeterministic Polynomial Time)

- It means these are problems where finding a solution might be difficult, but checking whether a given solution is correct can be done quickly.

### 3 examples of problems that are in NP 

## Traveling Salesman Problem

- A delivery driver needs to visit several cities and return to the starting point while keeping the total distance within a certain limit. Finding the best route can be difficult because there are many possible routes. However, if someone gives us a route, a Java program can quickly calculate the total distance and check whether it meets the limit.

## Sudoku Puzzle

- Sudoku is a puzzle where we fill a 9×9 grid with numbers from 1 to 9. Each row, column, and 3×3 box must contain each number only once. Finding the correct numbers can be challenging, but once the puzzle is completed, a Java program can easily check whether the solution follows all the rules. Larger versions of Sudoku can be much harder to solve.

## Subset Sum Problem

- Let's say we have a list of numbers: 2, 4, 6, 8, 10, and we need to find numbers that add up to 14. One possible answer is 4 + 10 = 14. Finding the right combination can become difficult when the list contains thousands of numbers. However, a Java program can quickly add the selected numbers to check whether they equal 14.

### Difference between universality, computability, and intractability

## Universality

- Java can do many different tasks. For example, we can use Java to create a calculator, a game, or a student registration system. The same programming language can handle different types of problems.

## Computability

- Can the problem be solved? For example, Java can calculate the sum of two numbers, such as 5 + 10 = 15. However, no program can correctly predict whether every possible program will eventually stop running.

## Intractability

- The problem can be solved, but it takes too long. For example, a Java program can find the shortest route between several cities. Finding the best route for 5 cities might be easy, but checking every possible route for 100 cities could take an extremely long time.
